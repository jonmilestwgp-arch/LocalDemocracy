Council Structure Map

People, entities, and the roles and relationships that connect them.

Load:

File formats
  • People.csv — Id, Name, Comments, PictureUrl
  • Entities.csv — Id, Name, EntityType, Funding, Color (Color is optional and overrides the type's colour)
  • EntityRole.csv — PersonId, EntityId, Role (one row per role; add more rows for more roles)
  • EntityConnections.csv — EntityId1, EntityId2, ConnectionType
  • Relationships.csv — PersonId1, PersonId2, Relationship (write "Parent/Child" for a directional one: first word describes Person 1)
  • EntityTypes.csv — EntityType, Color, Icon (a Font Awesome class such as fa-solid fa-tree). Any type not listed still works, with an automatic colour and icon.
